# 接口自动化框架使用说明

基于 **Pytest + Requests + Excel 数据驱动 + Allure**，在 Excel 里写接口用例即可执行。

---

## 1. 环境准备

- Python 3.x
- 安装依赖：`pip install -r requirements.txt`  
  （pytest、requests、openpyxl、jsonpath、jinja2、allure-pytest、pymysql）
- 本机已配置 Allure 命令行
- 被测接口服务已启动（默认：`http://localhost:3000`）

---

## 2. 目录说明

| 目录/文件 | 作用 |
|-----------|------|
| `config/config.py` | 基地址、用例文件、超时、数据库配置 |
| `data/` | Excel 接口用例 |
| `utils/` | 读用例、发请求、断言、提取变量、Allure 工具 |
| `testcases/test_runner.py` | 执行入口：解析 → 请求 → 断言 → 提取 |
| `run.py` | 一键执行并生成/打开 Allure 报告 |
| `report/` | Allure 报告 |
| `log/` | 运行日志 |
| `file/` | 上传文件存放目录 |

---

## 3. 配置说明

编辑 `config/config.py`（也可用环境变量覆盖）：

```python
BASE_URL = "http://localhost:3000"           # 接口基地址
EXCEL_FILE = "./data/mtm_api_cases.xlsx"     # 用例文件
SHEET_NAME = "Sheet1"
REQUEST_TIMEOUT = 10
```

换环境时主要改 `BASE_URL` 和 `EXCEL_FILE`。

---

## 4. 用例编写（Excel）

第 1 行中文表头，第 2 行英文字段，第 3 行起写用例。**一行 = 一个接口步骤。**

| 字段 | 说明 |
|------|------|
| id | 用例编号 |
| feature / story / title | 模块、场景、标题（进 Allure） |
| method / path | 请求方式、路径（拼在 BASE_URL 后） |
| headers / params / data / json / files | 请求头、URL 参数、表单、JSON 体、上传文件 |
| check / expected | JSONPath 精确断言；无 check 时 expected 做响应文本包含断言 |
| status_code | 预期状态码，空则默认 200 |
| sql_check / sql_expected | 可选：数据库断言 |
| jsonExData / sqlExData | 从响应或 SQL 提取变量，供后续步骤使用 |
| is_true | 是否执行，填 `True` |

**注意：**

1. `headers`、`params`、`data`、`json`、`jsonExData` 等必须是合法 **JSON 字符串**（双引号）  
2. 变量替换用 Jinja2：`{{TOKEN}}`、`{{PENDING_TASK_ID}}`  
3. 同一 `story` 内共享上下文；切换场景会清空变量  
4. 同场景若某步失败，后续步骤自动 skip  

**示例：**

| id | title | method | path | headers | params | check | expected | jsonExData | is_true |
|----|-------|--------|------|---------|--------|-------|----------|------------|---------|
| 1 | 重置数据 | post | /api/test/reset | | | $..reset | True | | True |
| 2 | 查待领取 | get | /api/tasks | {"X-Test-User-Id":"producer-lin"} | {"status":"PENDING"} | $..status | PENDING | {"PENDING_TASK_ID":"$.data[0].id"} | True |
| 3 | 领取任务 | post | /api/tasks/{{PENDING_TASK_ID}}/claim | {"X-Test-User-Id":"producer-lin"} | | $..status | IN_PROGRESS | | True |

**文件上传示例（files）：**

```json
{"file": ["1.jpg", "file/1.jpg", "image/jpeg"]}
```

---

## 5. 执行流程

每条用例按固定顺序执行：

1. 渲染变量（Jinja2）  
2. 解析请求参数  
3. 发送 HTTP 请求  
4. HTTP 断言（状态码 + check/expected）  
5. 可选 JDBC 断言  
6. 可选 JSON / SQL 提取到上下文  

---

## 6. 执行与报告

```bash
python run.py
```

流程：执行用例 → 生成 Allure 报告 → 自动打开浏览器。

- 报告：`report/test/html_report`
- 日志：`log/test.log`

也可：

```bash
pytest -vs ./testcases/test_runner.py
```

---

## 8. 扩展建议

1. 新接口：在 Excel 加一行，填 method/path 与断言即可  
2. 鉴权串联：登录接口用 `jsonExData` 提取 token，后续 headers 写 `"Authorization":"Bearer {{TOKEN}}"`  
3. 需要落库校验：填 `sql_check` / `sql_expected`，并配好 `config.py` 数据库信息
